# せかい地球儀 🌏

回して、タップして、世界の国を学べる 3D 地球儀（iPhone / iPad 対応の Web アプリ）。

**▶ https://alala3334.github.io/world-globe/**

Safari で開いて「共有 → ホーム画面に追加」するとアプリのように使えます。

## できること
- 地球儀を指で回す・ピンチで拡大縮小
- 国をタップ → Google 検索・ウィキペディアへのリンク、国旗・首都・人口・面積・人口密度・公用語・通貨・GDP・最高地点・となりの国・ウィキペディアの解説
- 「日本の約◯倍」「世界◯位」「東京からの距離」で比べて覚える
- 色分け表示：衛星写真 / 大陸 / 人口 / 面積 / 人口密度 / 1人あたりGDP
- 国名・首都のラベル表示、自動回転
- ランキング（人口・面積・GDP・最高峰・隣国の数など）
- クイズ：この国はどこ？ / 首都 / 国旗 / 光った国はどこ？（地域・難易度を選べる）

## データ出典
- 国境：Natural Earth（1:50m）
- 衛星写真：Esri World Imagery（拡大に合わせて高解像度を読み込み。オフライン時は NASA Blue Marble）
- 国の基本情報：mledoze/countries、Wikidata（人口・GDP・首都・最高地点など）
- 解説文：日本語版ウィキペディア（表示時に取得）
- 国旗画像：flagcdn.com
- 地球の画像・3D 描画：three-globe / globe.gl
